# Алгоритм сортування QuickSort

Програма для практичної: реалізація швидкого сортування (QuickSort) для масиву дробових чисел та оцінка його продуктивності.

## Що реалізовано

* **Особливості:** використання рекурсивної декомпозиції, вибір опорного елемента (півоти) як останнього в підмасиві та схема партиціонування Ломуто.

1. `partition` — розділення підмасиву відносно півоти та обмін елементів
2. `_quick_sort_internal` — рекурсивний спуск для сортування лівої та правої частин
3. `quick_sort` — універсальний метод сортування за зростанням або спаданням
4. `is_sorted` — перевірка коректності впорядкування масиву (`True` / `False`)
5. `benchmark` — тестування часу роботи на наборах з 1 000, 10 000 та 100 000 чисел
